# Changelog

Roomtone's own record. The files in `docs/release-*.md` and `fastlane/metadata/android/en-US/changelogs/` are the LatentJam history this tree inherits. They are not Roomtone releases. Issue numbers in those notes point at the LatentJam tracker.

## Unreleased

The project version is still **0.9.2** (Android `versionCode` 16), carried from LatentJam 0.9.2. No Roomtone build has been published to GitHub Releases, F-Droid, or the App Store.

- The visible name is Roomtone. The Android application id and the iOS bundle id are `io.github.djsecq.roomtone`.
- About, the privacy policy, the store listing, the website, and the AltStore source describe this repository: <https://github.com/dj-secq/roomtone>.
- A radio can start from a seed and keep choosing the songs that follow. For You can open one of those starts.
- A FLAC file that has no vendor string records `Roomtone` the first time this app edits it.
